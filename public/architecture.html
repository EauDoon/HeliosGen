      Desktop shell
      Starts the bundled Node sidecar on loopback and opens the application in the Tauri webview.
      
        src-tauri/src/lib.rs
        
      • opens the editor → Workflow canvas
      
      
      
      
      
        
      Workflow canvas
      Connects prompt, reference and generation nodes. The canvas submits the image request and can export the current workflow.
      
        components/WorkflowCanvas.tsx
        
      • submits an image job → Image request
      • saves workflow state → Workflow save
      • builds the portable archive → Workflow ZIP
      
      
      
      
      
        
      Image request
      Builds the model-specific request and, on the kie.ai path, starts a remote task. This path sends the prompt and selected references to the provider.
      
        app/api/generate/route.ts
        
      • prepares local references → Reference upload
      • starts status polling → Result polling
      
      
      
      
      
        
      Reference upload
      Uploads locally held reference images to the provider’s temporary file service so the remote model can read them.
      
        lib/kieUpload.ts
        
        
      
        
      
        
        
        Result polling
        Polls the submitted task, records completion and tries to save returned media locally. If copying fails, the provider URL can remain.
        
        lib/kieJobPoller.ts
        
        • mirrors returned media → Media files
        • records completion → SQLite
        
      
        
      
        
        
        Media files
        Writes media bytes to the configured media directory and returns a relative URL that the application can serve.
        
        lib/guest/localStorage.ts
        
          
      
          
      
          
        
          Workflow save
          Reads or saves workflow spaces through the local API. Space records include the canvas nodes and edges.
          
        app/api/workflows/route.ts
        
          • persists the canvas → SQLite
          
      
          
      
          
        
          SQLite
          Opens guest.db in the data directory. It holds workflow spaces, settings and generation records. Media files live separately.
          
        lib/guest/sqlite.ts
        
            
      
            
      
            
        
            Workflow ZIP
            Bundles workflow.json and available referenced media. When an asset cannot be read, the manifest keeps its original reference.
            
        lib/exportWorkflow.ts
